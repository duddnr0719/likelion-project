## 프로젝트 목표

쿼리 파라미터를 활용한 리스트 데이터 가공을 경험합니다.
- REST 설계 원칙: 단일 엔드포인트(URL 고정) + 쿼리 파라미터로 조건 제어
- DB 없이 Python 딕셔너리 데이터를 직접 가공
- CORS 설정을 통한 프론트-백 연동 경험

## 상세 기능 설명

### B-02. 키워드 검색

- 검색 대상: 여행지 이름, 설명, 태그
- 대소문자 구분 없음 (lower() 처리)
- 부분 일치 검색 (contains)

**예시:**
- `?search=해변` → 제주도, 강릉, 세부 등 '해변' 태그 또는 설명에 포함된 항목

### B-03. 카테고리 필터

- 카테고리 종류: `자연`, `역사`, `도시`, `휴양`
- 정확히 일치하는 항목만 반환

**예시:**
- `?category=자연` → 제주도, 강릉, 설악산

### B-04. 정렬

| sort 값 | 설명 |
|---------|------|
| `price_asc` | 가격 낮은순 |
| `price_desc` | 가격 높은순 |
| `rating_desc` | 평점 높은순 |
| `name_asc` | 이름 가나다순 |

### B-07. CORS 설정

- 개발 환경: `CORS_ALLOW_ALL_ORIGINS = True` (DEBUG=True 시)
- 프로덕션: `CORS_ALLOWED_ORIGINS` 리스트에 Vercel 도메인 명시
- 허용 메서드: `GET`, `OPTIONS`

## 데이터 구조

```python
{
    "id": 1,
    "name": "제주도",
    "category": "자연",        # 자연 | 역사 | 도시 | 휴양
    "region": "국내",           # 국내 | 해외
    "price": 350000,            # 예상 최저 비용 (원)
    "rating": 4.8,              # 평점 (1.0 ~ 5.0)
    "description": "...",
    "image": "https://...",
    "tags": ["자연", "해변"],
}
```

총 12개 여행지 데이터 (국내 6개, 해외 6개)
